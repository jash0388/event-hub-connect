Open Sans 1.10 supplies a consistent requested face for workbook cells, charts
and DrawingML text without requiring a local font installation. These four unmodified
TrueType fonts and LICENSE.txt come from Google's font repository at:
https://github.com/google/fonts/tree/beaec0837bd21524b57ecb435158f9011fc03999/apache/opensans

Copyright and license are also embedded in each font's name table.

This release predates the family's 2021 licensing change. Native XLSX and
clipboard content retain the requested family name; font files are served
locally without contacting a font provider.
