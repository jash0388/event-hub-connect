Your data

Exports, backups, and working offline

Keep a portable copy of your records and understand when offline changes have synced.

Puter·Product documentation·2 min read
On this page
  1. Choose CSV or a full backup
  2. Review before restoring
  3. Check sync before changing devices

Choose CSV or a full backup

In Settings, Export products as CSV downloads product data for a spreadsheet. Download backup creates a JSON file containing the account’s inventory records, settings, and history, including older activity archives.

Use the backup for a restorable copy of the dataset. CSV does not preserve everything a backup does. Keep separate copies of photo files you need independently: product photo references are not an embedded image archive.

Review before restoring

In Settings, choose Restore from backup, select the JSON file, and review the confirmation. Restoring replaces the current dataset; it does not merge it. Download a fresh backup of the current records first.

Automatic snapshots offer another recovery path before destructive operations. A snapshot is useful for undoing a recent mistake, while a downloaded backup is a copy you retain independently.

Check sync before changing devices

Your saved inventory uses your Puter account. After an online visit, the production app caches its shell and keeps a local mirror so it can continue through connection drops. Offline changes queue on this device until a connection returns.

The offline banner distinguishes local changes from changes that are syncing. Wait for syncing to finish before moving to another device or signing out. A first load, a new sign-in, or a device without cached data requires a connection.

Browser storage can be cleared or become unavailable. Keep downloadable backups instead of relying on the local mirror as your only copy.
