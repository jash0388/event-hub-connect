Settings: currency, thresholds, and planning defaults

Every preference in the app, what it changes, and what it deliberately does not.

Puter·Product documentation·2 min read
On this page
  1. Appearance and money
  2. Reorder planning defaults
  3. Data, backup, and the danger zone
  4. Your account

Appearance and money

Theme offers System, Light, and Dark. System follows your device setting. The choice is saved with your account, so it follows you to another device rather than living in one browser.

Currency is the currency purchase costs, selling prices, and stock value are shown in. It formats the numbers; it does not convert them, so changing it re-labels existing amounts rather than re-pricing them. Default low-stock threshold is the level used by any product that has not been given one of its own.

Reorder planning defaults

Safety days are added to a supplier’s lead time when Inventory suggests a reorder point, and they define what counts as running out soon. The default is three days. Coverage horizon is the number of days of demand a suggested order quantity aims to carry; left at zero, suggestions aim at roughly twice the threshold instead.

Both feed suggestions only. Nothing here writes a threshold onto a product or places an order, which is why the defaults can be opinionated without changing anything your account holds. Each accepts up to 365 days.

Data, backup, and the danger zone

Export products as CSV downloads the catalogue as a re-importable file, sorted by name. Import products from CSV opens the same wizard the Products page offers.

Download backup writes one JSON file holding everything in the account, including archived months of history. Restore from backup replaces the current data with a file you choose, after showing you what the file contains. Restore automatic snapshot appears when Inventory has taken one, and says when it was taken and what it sits in front of.

Erase all data clears every product, location, supplier, and history entry. Settings survive it, and a safety snapshot is saved first, so the page can restore what was there.

Your account

The Account row names the Puter account the data belongs to. Sign out ends the session and clears this device’s local mirror and any writes still queued on it, so the next person using the browser cannot read or replay your data.

If changes have not synced yet, the confirmation says how many would be lost, and asks in stronger terms. Wait for the offline banner to finish syncing first. Inside a Puter app window the platform owns the session, so no sign-out button is shown there.

The Help and resources rows at the top of Settings link to this documentation and to the guides.
