Review and recovery

Correct records and understand deletion

Correct security data, review linked-record restrictions, and understand how deletion and Undo affect certificates, awards, holders, and files.

Puter·Product documentation·3 min read
On this page
  1. Distinguish a correction from a new event
  2. Read restrictions before deleting a linked record
  3. Understand what deleting a certificate changes
  4. Review cascading deletion and attachments
  5. Verify Undo or use a restore point

Distinguish a correction from a new event

Use an edit to correct an incorrectly entered term. Use the appropriate lifecycle workflow for an event that actually occurred: exercise, settlement, cancellation, transfer, repurchase, departure, or conversion. Deleting a valid original grant is not how to record its later cancellation.

  1. Compare the current record with the supporting agreement and transaction evidence.
  2. Export a company backup if the correction affects several connected records.
  3. Open the security’s pencil action and review its View history link.
  4. Enter the correction and an optional Reason for change, then choose Save changes.
  5. Recheck the holder, ownership totals, plan movements, and affected reports.

Correcting a historical term can change an earlier-date report. Retain previously reviewed exports when they are needed to explain what was reported at that time.

Read restrictions before deleting a linked record

The app refuses some edits or deletions because later records depend on the original quantity, date, or holder. An exercised option or settled RSU cannot be deleted while its linked certificates remain. A transferred certificate cannot be deleted while its successors remain. A converted SAFE or note cannot be deleted while its conversion certificate remains.

A refusal identifies the records to inspect. Do not remove a valid chain merely to make an unrelated edit pass. If the underlying event was entered incorrectly, review the whole chain and available recovery points first.

Understand what deleting a certificate changes

Effects of deleting a linked certificate
CertificateRecorded effect
Exercise certificateThe exercise remains on the option grant. The quantity becomes uncertified and can receive a certificate again without another exercise.
RSU settlement certificateIts units return to the originating RSU as unsettled.
SAFE or note conversion certificateThe linked source instrument becomes an outstanding convertible again.
Successor from a transfer or partial repurchaseWhen the chain permits reversal, deletion removes the event’s other successor records and reopens the original certificate.

Read the specific confirmation before proceeding. Onward transfers or later repurchases can prevent reversal of an earlier transfer. Deleting one certificate from a closed financing does not reverse every other certificate, class change, or reserve increase from that financing.

Review cascading deletion and attachments

Deleting a stakeholder also deletes that holder’s securities when the dependency checks allow it. This changes ownership. Use Mark departed for an actual departure; a departed holder can still own shares or hold exercisable options.

When affected records carry attachments, the dialog offers Delete, keep files or Delete files too. Undo can restore records but cannot recreate a file that was actually deleted. File references in another company or restore point can affect cleanup.

Verify Undo or use a restore point

Security, stakeholder, and saved-scenario deletion offer an Undo action in the result notification. Use it while available, then verify the restored records. Undo can be refused if the company or relevant data has changed; it is not an unlimited editing history.

Valuation and equity-plan deletion do not offer the same Undo action. Use retained source records and backups to plan corrections. For a broader reversal, follow Restore company data, which explains the company-wide scope and retention limits. Permanent History records corrections, deletions, undo operations, and restores.
