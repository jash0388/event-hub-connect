Noto Sans KR Regular and Bold, version 2.004

Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.

Static TrueType instances (wght=400 and wght=700) of the Korean regional variable
font from the Noto CJK project, generated with fonttools 4.59.2:
https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/Variable/TTF/Subset/NotoSansKR-VF.ttf

Reproduce from the repository root with: python scripts/korean-fonts.py
TrueType is used because the current PDF writer corrupts CID-keyed CFF subsets.
Glyph data is padded to four bytes for fontkit's short loca subset offsets.
